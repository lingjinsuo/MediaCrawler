3. 技术规范：Python 3.11+ 异步编程规范、FastAPI 0.110 / Pydantic 2.5 接口契约、SQLAlchemy 2.0 异步 ORM、Playwright 1.45 CDP 协议、HTTP/2 与 TLS 1.2+、MySQL 8.0；
4. 平台合规：各目标平台（小红书、抖音、快手、B站、微博、贴吧、知乎）的用户协议与 robots.txt 规范，采集频率与数据用途受限；
5. 公司标准：《MediaCrawler 项目开发与交付标准 V1.0》、《开发需求文档》V1.0、《设计开发说明书》V1.0（2026-10-12）。

本项目交付物为一套多平台电商评论舆情采集分析系统，涵盖以下主要功能、技术指标与结构：
（A）多平台采集引擎：小红书、抖音、快手、B站、微博、贴吧、知乎 7 平台，支持关键词搜索、指定帖 ID、创作者主页三种采集模式，支持 Cookie / 扫码 / 手机号三种登录方式，支持 CDP 模式接管本机真实浏览器；
（B）数据存储层：支持 JSON / JSONL / CSV / Excel / SQLite / MySQL / PostgreSQL / MongoDB 八种后端，含去重逻辑与字段超长截断；
（C）购买意图识别：基于运营维护的关键词词库自动判定评论是否具备购买意图，命中即写入独立线索池表，形成「待处理 → 已处理」工单闭环；
（D）线索推送管理：线索列表分页、多维筛选（平台 / 状态 / 时间区间 / 关键词）、批量处理、按命中关键词聚合统计；
（E）Web 控制台：统一侧边栏框架下的 5 个功能页面（原始抓取、一键抓取、评论推送、数据浏览、系统设置），WebSocket 实时日志推送；
（F）数据洞察：按平台 / 关键词 / 时间的采集量与线索命中量趋势看板，线索批量导出；
（G）运维支撑：一键启动与重启脚本、环境隔离、监控告警、CI 流水线、运维手册与接口文档。

设计内容（包括产品主要功能、性能、技术指标，主要结构等）：

主要技术特点：
1、采用 Python 3.11 + FastAPI + Playwright 异步架构，采集任务以 subprocess 进程隔离运行，避免浏览器上下文异常污染 Web 服务进程；
2、通过 Chrome DevTools Protocol (CDP) 接管本机真实 Chrome/Edge 浏览器，复用真实 Cookie 与设备指纹，显著降低平台风控拦截概率；
3、自研风控对抗四层防御体系（预防 / 识别 / 指数退避重试 / 优雅降级），针对抖音 ArgusSecurityPlugin 拦截实现 Cookie 自动刷新与空数据降级；
4、采用 AbstractCrawler / AbstractStore 抽象基类 + 工厂注册模式实现平台可插拔，新增平台不改动框架代码；
5、统一以秒为时间戳单位入库，跨平台时间语义归一；线索池独立建表并配置三组复合索引支撑高频筛选聚合；
6、配置分层管理：静态配置走 Git、环境配置走 .env、运行配置走 mc_setting 表且即时生效，无需重启服务。

技术指标：
1、线索列表接口 P95 响应时间 ≤ 500 ms（10 万条线索量级），跑批任务单平台处理 500 条评论 ≤ 60 s；
2、抖音平台单轮采集成功率 ≥ 90%，风控触发后可自动恢复而不中断整条采集链路；
3、7 平台全链路端到端可用，浏览器控制台首屏加载 ≤ 3 s；
4、自动化测试通过率 100%（当前基线 80 passed / 23 failed，修复计划见《开发需求文档》T-6.1~T-6.5）。

其他指标：
1、提供《部署与运维手册》《API 接口文档》《数据字典》各一份（含部署、配置、监控、排障指引）；
2、提供完整培训：远程 1 次集中讲解 + 3 个月内不限次答疑（维护期内）。
